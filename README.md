# Sales Performance Analysis Dashboard

## Project Overview

The **Sales Performance Analysis Dashboard** is an interactive Excel-based data analytics project created to analyze sales performance and present key business metrics in an easy-to-understand format.

The project analyzes sales data to identify patterns in revenue, profit, units sold, product performance, location-wise performance, and daily revenue trends. The analysis was organized using Pivot Tables, Excel formulas, and visualizations and presented through a single interactive dashboard.

## Key Metrics

* Total Orders
* Units Sold
* Total Revenue
* Total Profit
* Average Revenue
* Average Profit

## Analysis

* **Revenue by Location** – compares revenue generated across different locations.
* **Revenue by Product** – analyzes revenue performance across products.
* **Profit by Location** – compares profitability across different locations.
* **Daily Revenue Trend** – shows how revenue changes over time.

## Interactive Dashboard

The dashboard provides a consolidated and interactive view of sales performance through KPI cards, charts, slicers, and filters.

Users can dynamically filter the dashboard using available fields such as:

* Date
* Product
* Category
* Location
* Salesperson

This allows users to explore the data, compare performance, and analyze sales trends based on different selections.

1. Organized and prepared the sales data.
