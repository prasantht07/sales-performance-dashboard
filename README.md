# Sales Performance Analysis Dashboard

## Project Overview

The **Sales Performance Analysis Dashboard** is an Excel-based data analytics project created to analyze sales performance and present key business metrics in an easy-to-understand format.

I worked with sales data to identify patterns in revenue, profit, orders, units sold, and daily sales performance. The analysis was organized using Pivot Tables, Excel formulas, and visualizations and presented through a single interactive dashboard.

## Key Metrics

* Total Orders
* Units Sold
* Total Revenue
* Total Profit
* Average Revenue
* Average Profit

## Analysis

* **Revenue by Location** – compares revenue generated across different locations.
* **Revenue by Product** – analyzes revenue performance across products.
* **Profit by Location** – compares profitability across different locations.
* **Daily Revenue Trend** – shows how revenue changes over time.

## Dashboard

The dashboard provides a consolidated view of sales performance through KPI cards and charts, making it easier to understand important business metrics and identify sales trends.

## Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Excel Formulas
* KPI Analysis
* Data Visualization
* Dashboard Development

## Project Workflow

1. Organized and prepared the sales data.
2. Used Excel formulas to calculate required metrics.
3. Created Pivot Tables for different business views.
4. Calculated key performance indicators.
5. Created charts to visualize sales trends and comparisons.
6. Combined the analysis into a professional dashboard.

## Key Learning

This project helped me strengthen my practical skills in **Excel-based data analysis, KPI development, Pivot Tables, data visualization, and dashboard creation**. It also helped me understand how raw business data can be transformed into meaningful information for decision-making.
